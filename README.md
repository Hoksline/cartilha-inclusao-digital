# Conecta Melhor — Cartilha Interativa de Inclusão Digital

Projeto frontend feito para um público idoso, com foco em:
- Navegação simples;
- Botões grandes;
- Texto ampliado;
- Layout responsivo para celular, tablet e computador;
- Identificação de Fake News;
- Prevenção contra golpes no WhatsApp;
- Segurança em aplicativos bancários;
- Quiz interativo;
- Checklist de segurança.

## Como executar no VS Code

1. Extraia a pasta do projeto.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito e escolha **Open with Live Server**, caso tenha a extensão Live Server instalada.
5. Se não tiver, também é possível abrir o `index.html` diretamente no navegador.
